# plaintext — brand

Typographic marks, rendered from HTML via headless Chrome at 3× (source .html kept in git history).
Font: system mono (SF Mono / Menlo). Palette is the project's own (research-derived, never attributed).

## Palette
- Deep navy   #1F437E   (wordmark, headings)
- Signal blue #2D5FB6   (cursor, accents)
- Bright blue #2CBFF2   (icon gradient top)
- Paper       #F4F4F4 / #F6FAFF (icon sheet, cream text)

## Files
- `wordmark.png`         2700×780, transparent — mono "plaintext" + block cursor, masthead corner ticks
- `icon-sheet*.png`      paper tile, navy ".txt" in a frame (works on light/mono surfaces)
- `icon-blue-txt*.png`   glossy blue tile, cream ".txt" (app-icon / avatar)
- `*-512 / -180 / -32`   favicon, apple-touch, and full sizes
